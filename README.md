# 🚀 Capítulo 4: Práticas de Fundamentos e Estruturas de Dados

"A tecnologia ganha propósito quando a teoria se encontra com a prática. Este repositório é o canal onde as habilidades são lapidadas e validadas."

Este repositório reúne as atividades práticas desenvolvidas durante o bootcamp da **Generation Brasil**. Ele funciona como um portfólio vivo e um canal de acesso direto para que o **instrutor** possa validar a aplicação dos conceitos aprendidos em aula.

---

## 📖 A HISTÓRIA

Neste capítulo, a minha jornada deixou de ser sobre aprender comandos e passou a ser sobre resolver problemas. Através de desafios propostos pelo instrutor, mergulhei na construção de algoritmos que exigem não apenas sintaxe, mas estratégia. 

A transição do JavaScript para o TypeScript trouxe a maturidade necessária para entender que a organização dos dados é tão importante quanto a lógica. De sistemas simples de decisão a estruturas complexas de Pilhas e Filas, cada linha de código aqui é um passo na consolidação do meu perfil como desenvolvedora Full Stack.

---

## 💻 CONTEÚDO E VALIDAÇÃO TÉCNICA

Os ficheiros aqui presentes foram desenvolvidos com base em questões exclusivas passadas em aula (os enunciados não constam neste repositório). 

### 🟢 Lógica Aplicada (JavaScript)
* **Algoritmos de Fluxo:** Exercícios de repetição e condicionais complexas.
* **Dados Multidimensionais:** Manipulação intensiva de Vetores e Matrizes.

### 🔵 Estruturas Avançadas (TypeScript)
* **Segurança e Tipagem:** Implementação de soluções usando TypeScript.
* **Collections:** Uso de `Set` e `List` para gestão de dados.
* **Estruturas Lineares:** Desenvolvimento de sistemas de Fila (Queue) e Pilha (Stack) para fluxos de dados organizados.
